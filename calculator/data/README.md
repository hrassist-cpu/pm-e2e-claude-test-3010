# Дані для етапу 4 «Калькулятор»

Усі дані навчальні.

Задачі, стадії й людино-дні бери зі своєї оцінки (03). Готової розкладки Christmas тут немає. Оцінку можна покласти сюди як CSV.

## `roster.csv`
Склад команди: з нього інструмент обирає людей під твій план і рахує собівартість. `rate_per_day` — собівартість, $/людино-день. `quality_1_5` — наша внутрішня оцінка якості від 1 (нижча) до 5 (вища); при підборі команди можна врахувати відповідність задачі й потребу в перевірці. `speed_factor` — у скільки разів реальний час людини відрізняється від оцінки (дні задачі × speed_factor: 0.8 швидше, 1.3 повільніше). `w1…w4` — кількість доступних робочих днів спеціаліста на тиждень, не конкретні дати. Які саме дні — на твій розсуд: запиши припущення, не перевищуй тижневий ліміт. `note` — обмеження спеціаліста (зайнятість, відпустка, досвід, особливості роботи); враховуй їх разом із числовими колонками.

Якщо захочеш врахувати доступність: W1 = 15–19.11, W2 = 22–26.11, W3 = 29.11–03.12, W4 = 06–10.12. Старт не раніше 15.11 (погодження до старту — твоє припущення, а не обіцянка Jina). Дедлайн, якщо не домовився інакше: 10.12.

## `08-rate-card.md`
Ставки й правила: $300 за людино-день клієнту, лід — окремим рядком (у ціні для клієнта й у собівартості), два раунди правок у ціні, додатковий скоуп окремо.
