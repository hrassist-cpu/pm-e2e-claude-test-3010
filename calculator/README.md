# Етап 4. Калькулятор ресурсів

Естимація є, тепер треба обрати команду, щоб маржа була вигідною.

У тебе є (усе в цій папці, `calculator/data/`):
- `roster.csv` — склад команди (що означає кожна колонка — у [data/README.md](data/README.md));
- `08-rate-card.md` — ставки й правила;
- твоя оцінка із зупинки 03.

## Зроби
- Інструмент — таблицю, скрипт, вебсторінку, будь-що, що допоможе порахувати маржинальність (виручку й собівартість) на команді з ростера. Усе, що захочеш додати до функціоналу, — плюс.
- Порахуй планову маржинальність Christmas Reskin.

## Здати
- інструмент — сюди, у `calculator/`, з короткою інструкцією, як запустити (у цьому README або окремим файлом);
- планову маржинальність — файлом у застосунку.

Де що здаєш — у [README репозиторію](../README.md#де-що-здаєш).
