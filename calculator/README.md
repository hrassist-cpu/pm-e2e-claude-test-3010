# Калькулятор маржі Christmas Reskin

Скрипт `margin_calc.py` рахує виручку, собівартість і планову маржинальність за ростером з `data/roster.csv`.

## Як запустити
```
python margin_calc.py 28 "Світлана,Марія,Олександр"
```
Перший аргумент: людино-дні з естимації, другий: люди з ростера через кому. Ліда додає за нормою 2 дні на локацію.
